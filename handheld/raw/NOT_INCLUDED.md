# 未包含的内容（以及为什么）

本包是“为三个问题服务”的证据包，不是整机备份。以下**未包含**：

| 内容 | 大小/位置 | 为什么 |
|---|---|---|
| ONNX 权重 | 约 926 MB，`运控模型库/真机/*/模型/` | 只给 `raw/model_io.txt` 的 IO 形状；权重是训练资产，不公开 |
| 真机日志全量 | `c2_events.log` 10.8 MB | 只抽了 UC3 的状态时间线与 4 个窗口（`raw/logs/`） |
| 真机二进制 | `mc` / `device_manager` 等 | 闭源；分析只能靠配置与接口 |
| `roboto_origin-main` | 约 2.1 GB | 另一个产品的开源参考，与 T1 牵手机制无直接关系 |
| 动作轨迹 CSV | `res/**/*.csv`，数百 MB | 与牵手判定/解算无关 |
| gimbal 轨迹 CSV | `classic/gimbal/*.csv`，约 1.9 MB | `bi_gimbal` 的抬臂轨迹；本任务只需要 `user_arm` 字段 |
| 其余 RL 配置 | `rl/` 下 40+ 份 | 只保留 WBC/GIMBAL/WALK/QUAD/变身/动画等与判定、切换、对照相关的 |
| 接口 Rust 绑定 | `aimdk_msgs/rust/**` | 与语义无关的生成代码 |
| 2026-11-25 旧输入包 | 仓库根目录（非 `handheld/`） | 另一主题；本任务不需要，prompt 已要求不要读 |

需要以上任一项时，让用户从工作区补齐；**不要在报告里假装读过**。
